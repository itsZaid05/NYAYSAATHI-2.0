# UK Legal Data Research (verified 2026-10-17 via official docs)
## A. legislation.gov.uk — VERIFIED, USABLE
API = website URLs + `/data.xml|data.rdf|data.feed`; search Atom feeds paginated (default 20, `results-count=N`, `<link rel=next>`); versions: `/ukpga/2021/1/data.xml` (latest), `/enacted`, point-in-time `/resources/1999-09-27/data.xml`; CLML XML with ukm:Metadata (title,type,year,number,enactment/in-force dates, unapplied effects). Licence: **Open Government Licence v3.0 — commercial use, adaptation, caching, embedding permitted with attribution** ("© Crown and database right…legislation.gov.uk"). Caveats: dual-licensed EUR-Lex/Westlaw-derived content; revised vs enacted distinction; do not label "in force" unless metadata supports it. No auth, no published hard rate limit → polite UA, caching, backoff.
## B. Find Case Law (TNA) — VERIFIED, LICENCE-GATED
Public API docs: nationalarchives.github.io/ds-find-caselaw-docs/public (OpenAPI 0.6.0); judgments as LegalDocML XML, Atom search feeds. **Open Justice Licence v2.0 permits reading/downloading/commercial incorporation but EXCLUDES computational analysis** (bulk programmatic search, indexing, NLP, embeddings/vector DBs, LLM/AI product building). That requires a free **Computational Analysis Licence** (R&D 1yr / Transactional up to 5yr; Discovery Board monthly; "fully automated legal advice" & outcome prediction are high-risk). **STATUS: NOT APPLIED FOR — unresolved blocker requiring owner approval (organisational details needed).** Implementation: provider built behind `CASELAW_LIVE_ENABLED=true` + `CASELAW_COMPUTATIONAL_LICENCE_CONFIRMED=true` gates; default OFF, returns explicit unavailable, never falls back to synthetic cases. Single user-initiated search-and-display may fall under OJL, but we take the conservative reading until TNA confirms in writing (caselawlicence@nationalarchives.gov.uk).
